# HotelAPI

O **HotelAPI** é uma aplicação web full-stack para gerenciamento de solicitações e operações de hotelaria.

O projeto foi desenvolvido com **ASP.NET Core** no backend e **React** no frontend, aplicando conceitos de arquitetura em camadas e comunicação em tempo real com SignalR.

## Funcionalidades

- Cadastro e gerenciamento de solicitações
- Atualização em tempo real via SignalR
- Regras de negócio aplicadas no backend
- Geração de relatórios em PDF
- Interface web responsiva

---

## Arquitetura

O backend segue uma estrutura em camadas:

Separação de responsabilidades:
- Controllers: entrada das requisições
- Services: regras de negócio
- Repositories: acesso ao banco
